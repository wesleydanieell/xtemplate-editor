TEMPLATE VARIABLES

Variables control the entire template. They do not belong to a specific element: you must use them in a property or expression. Lengths/numbers go in expressions (e.g. row); color variables go directly in Stroke/Fill (e.g. lineColor). The preview value changes the drawing here; the default is saved in the exported file.
